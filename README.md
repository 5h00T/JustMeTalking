# Just Me Talking

YouTube Liveのチャット欄に、自分のチャンネルのコメントだけを表示するChrome拡張です。初回に自分を登録すると、新着コメントにもフィルターが適用されます。

## インストール

1. コードをダウンロードし、ZIPを展開します。
2. Chromeで chrome://extensions/ を開きます。
3. 右上の「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開したフォルダを選択します。

## 使い方

1. YouTubeのライブチャットを開きます。
2. チャット上部に追加された「自分を指定」を押します。
3. チャット内に表示されている自分が投稿したコメントをクリックします。
4. 「自分だけ：ON」になり、登録したチャンネルのコメントだけが表示されます。

「自分だけ：ON / OFF」で全員表示に戻せます。「自分を変更」で別のチャンネルを登録できます。選択中は全員のコメントが表示され、Escで選択を取り消せます。拡張機能のポップアップからもON/OFFと登録解除ができます。

まだ自分のコメントがない場合は、拡張機能のポップアップを開き「チャンネルIDで指定する」に自分のチャンネルID（`UC`で始まる24文字）を入力してください。
